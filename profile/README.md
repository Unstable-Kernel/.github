# UNSTABLE KERNEL

Building autonomous and intelligent systems inspired by nature, emergence, and distributed intelligence.

Right now the focus is on:

* simulation-first autonomy
* swarm intelligence
* adaptive systems
* machine reasoning
* interactive intelligence
* biologically inspired coordination systems

The goal is simple:
make intelligent systems feel accessible, observable, and usable instead of locked behind giant labs and billion-dollar companies.

Started with a student budget, too many ideas, and the irrational belief that small teams with enough curiosity can still build things that matter.

Still early.
Still unstable.
Probably a good sign.
